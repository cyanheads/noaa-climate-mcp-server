# 0.8.0 — 2026-11-03

## Added

- Add the noaa-climate-guide skill and MCP resource.
- **GHCND flags** decode measurement, quality, source, and observation time beside raw attributes; a page-local notice identifies failed quality checks without dropping values ([#52](https://github.com/cyanheads/noaa-climate-mcp-server/issues/52)).
- **Agent Plugins manifests** add root `plugin.json` and `mcp.json`, retaining client overlays for credential forwarding.

## Changed

- **Observation `value` is optional.** Identified PRECIP_HLY/HPCP and PRECIP_15/QPCP missing sentinels now omit `value` and set `missing: true`. Callers must check for missing observations before arithmetic; never substitute zero ([#48](https://github.com/cyanheads/noaa-climate-mcp-server/issues/48)).
- **Station IDs** normalize case, surrounding whitespace, and bare GHCN aliases across tools and the station resource; ambiguous bare IDs and empty namespace/payloads are rejected with examples ([#51](https://github.com/cyanheads/noaa-climate-mcp-server/issues/51)).
- **Raw-unit guidance** states datatype-qualified examples and NOAA documentation for each admitted dataset when units are omitted, including empty pages ([#50](https://github.com/cyanheads/noaa-climate-mcp-server/issues/50)).
- **Development tooling** refreshes framework skills, packaging validation, audit attribution, issue-form environment fields, and the one-day dependency release-age policy; installation docs use concise hosted/local commands.

## Fixed

- **Oversized observation queries** fail before fetch or retry above 4000 encoded characters, with guidance to reduce filters and make separate calls ([#49](https://github.com/cyanheads/noaa-climate-mcp-server/issues/49)).
- **MCPB bundles** exclude development files, node-gyp intermediates, and build-only dependency content while preserving SDK skill runtime modules and the published guide.
