# 0.6.5 — 2026-10-08

## Changed

- **Argument repair** — a numeric string for a number field (`limit: "3"`), a boolean string (`summary: "false"`), a lone string for a list field (`datatypeId: "TMAX"` → `["TMAX"]`), and `null` at an optional key (dropped) are repaired before validation (mcp-ts-core 0.13.14); an integer sent for a string field becomes its digits (`stationId: 12345` → `"12345"`) (mcp-ts-core 0.13.9).
- **Tool error results** end with `request <id>` in `content[]` and carry `data.requestId` (mcp-ts-core 0.13.10).
- **Network-failure messages** name the NOAA URL by origin only — `https://www.ncei.noaa.gov/…?…` where 0.6.4 showed the endpoint path (mcp-ts-core 0.13.12).
- **Recovery hints** are filled from each tool's declared error contract by the framework (mcp-ts-core 0.13.10) instead of forwarded at every throw site; the hint text callers receive is unchanged.
- **Upstream-outage errors** in the eight CDO tools (`noaa_climate_fetch_data`, `noaa_climate_find_locations`, `noaa_climate_find_stations`, `noaa_climate_get_station`, `noaa_climate_list_data_categories`, `noaa_climate_list_data_types`, `noaa_climate_list_datasets`, `noaa_climate_list_location_categories`) are thrown with literal `rate_limited` / `service_unavailable` reasons, so `lint:mcp`'s error-contract checks now inspect them; the code, reason, message, and recovery hint a caller receives are unchanged ([#35](https://github.com/cyanheads/noaa-climate-mcp-server/issues/35)).
- **`server.json`** npm entries drop the `run start:*` package arguments and set `runtimeHint: "npx"`; the `streamable-http` entry sets `MCP_TRANSPORT_TYPE` to the fixed value `http` (mcp-ts-core 0.13.11 template).
- **Docker image** installs production dependencies in a build-platform `deps` stage, cross-installed for the target arch so multi-arch builds no longer run Bun under QEMU (mcp-ts-core 0.13.10); installs OTel packages through `scripts/install-otel.ts` (0.13.10) and prunes musl-only packages (0.13.11). Base images move Bun 1.4.0 → 1.4.2.
- **Minor/internal:** start scripts run `node dist/index.js` with a new `start` script, `test` scripts call `vitest run`, `rebuild` calls `scripts/build.ts` directly, `README.md` tool sections tightened and `OTEL_EXPORTER_OTLP_ENDPOINT` / `LOG_TOOL_FAILURE_PAYLOADS` documented as opt-ins, `.env.example` rewritten to the template's framework blocks, `.gitignore` / `.dockerignore` ignore `.env*` (examples kept; registry token files excluded from the image), `.mcpbignore` excludes `tests/`, `logs/`, `.cache/`, `coverage/`, and `docs/idea.md`, `!dist/*.mcpb` added to `files`, CodeQL workflow split into per-language jobs, `scripts/lint-mcp.ts` fails on a definition that does not import, `scripts/lint-packaging.ts` and `scripts/release-github.ts` extended, `scripts/split-changelog.ts` removed, `framework-skills/` resynced, `CLAUDE.md`/`AGENTS.md` and the feature-request form reworded to the template.
