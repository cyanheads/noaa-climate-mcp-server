# 0.6.3 — 2026-09-16

## Changed

- **Argument rejection** (undeclared root key, wrong type, or missing field) now returns `isError: true` with `structuredContent.error` carrying `-32602` (`InvalidParams`) alongside the `content[]` text; previously no `structuredContent` was included.
- **`sessionMode: 'stateless'`** declares the HTTP session posture in `src/index.ts`; with `MCP_SESSION_MODE` unset the server resolves `stateless`, and an exported `MCP_SESSION_MODE` value still overrides it.
- **The server card** at `/.well-known/mcp.json` now publishes the resolved session mode under `_meta` key `io.github.cyanheads.mcp-ts-core/sessionMode` (`stateless` here).
- **`SIGTERM`/`SIGINT`** now end the process explicitly — exit `0` once shutdown settles, `1` if the 10s ceiling fires.
- **Framework skills** moved from `skills/` to `framework-skills/`, so a plugin install no longer ships this server's development skills.
- **Bun engines floor** raised to `>=1.4.0`.
- **Minor/internal:** `.env.example` session-mode comment, README `MCP_SESSION_MODE` row and Bun badge, `AGENTS.md` added as a byte copy of `CLAUDE.md`, Dockerfile aligned to the template (BuildKit cache mounts, bare OCI title, `bun run build`), `audit:fix` script, `devcheck.config.json` outdated allowlist cleared, `.mcpbignore` path-anchored, issue forms accept blank issues and link the private advisory form, CONTRIBUTING/SECURITY wording, skills and scripts resynced.

## Fixed

- **A CDO HTTP 500** now classifies `ServiceUnavailable` and is retried with backoff, so CDO-backed tools report it under their declared `service_unavailable` reason; previously a 500 classified `InternalError` and failed on the first attempt.
- **Both plugin manifests** replace the literal placeholder `"your-noaa-climate-token"`: Claude Code declares `NOAA_CDO_TOKEN` as `userConfig` (`${user_config.NOAA_CDO_TOKEN}`, prompted at install), Codex lists it in `env_vars` (picked up from the environment).
