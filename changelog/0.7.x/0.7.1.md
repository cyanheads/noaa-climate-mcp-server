# 0.7.1 — 2026-10-22

## Changed

- **Read page limits:** clamp oversized positive integers to 1000 for CDO and 100 for bulk corpora, disclosing requested/applied values alongside paging guidance; log and count each clamp. Set `NOAA_CLAMP_LIMITS=false` to restore ceiling rejection across installation surfaces ([#43](https://github.com/cyanheads/noaa-climate-mcp-server/issues/43)).
- **Storm date intervals:** accept optional inclusive `YYYY-MM-DD` overlap bounds before counts and paging, echoing `appliedDateRange`; date-filtered searches exclude missing or invalid source spans and still read only the selected year ([#44](https://github.com/cyanheads/noaa-climate-mcp-server/issues/44)).
- **Identifier schemas:** advertise episode-ID and postal-code patterns while preserving trimming and leading zeros; malformed states now fail argument parsing, replacing `invalid_state_code`, while unavailable codes retain `unknown_state` ([#46](https://github.com/cyanheads/noaa-climate-mcp-server/issues/46)).
- **Bun:** 1.4.3 → 1.4.4 for package-manager and container pins; synchronize query and configuration documentation.

## Fixed

- **Discovery date ordering:** reject reversed ranges before requests on five discovery tools with `validation_error`, offending dates, and recovery guidance ([#20](https://github.com/cyanheads/noaa-climate-mcp-server/issues/20)).
- **Dataset coverage:** filter the complete matching catalog by normalized inclusive date overlap before totals and pagination; bound catalog retrieval and fail incomplete responses ([#40](https://github.com/cyanheads/noaa-climate-mcp-server/issues/40)).
- **Station extents:** reject malformed, nonfinite, and out-of-bounds coordinates locally; preserve decimal/scientific syntax, equal bounds, and reversed-axis empty-query behavior ([#41](https://github.com/cyanheads/noaa-climate-mcp-server/issues/41)).
- **Disaster archive guidance:** disclose NOAA's retired 1980–2024 product on every successful response and describe CPI adjustments as archived, without current-price rebasing or an inferred base year ([#42](https://github.com/cyanheads/noaa-climate-mcp-server/issues/42)).
- **Storm narratives:** preserve literal punctuation and line breaks when rendering event and deduplicated episode narratives as CommonMark ([#45](https://github.com/cyanheads/noaa-climate-mcp-server/issues/45)).
