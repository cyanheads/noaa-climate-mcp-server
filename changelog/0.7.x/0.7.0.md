# 0.7.0 — 2026-10-18

## Added

- **Storm episode filter:** accept an optional literal digit-string `episodeId`, combined with the other year-scoped filters before counts and pagination ([#33](https://github.com/cyanheads/noaa-climate-mcp-server/issues/33)).
- **Storm calendar dates:** return optional local ISO `beginDate`/`endDate` from valid source calendar components, alongside raw date-time and timezone fields ([#34](https://github.com/cyanheads/noaa-climate-mcp-server/issues/34)).

## Changed

- **Storm narrative output:** replace per-event `episodeNarrative` with page-local `episodeNarrativeRef` and `episodeNarratives` ([#32](https://github.com/cyanheads/noaa-climate-mcp-server/issues/32)). Consumers must resolve each event's reference against the response dictionary; equal narrative text appears once.
- **Development guidance:** synchronize framework references for error bounds, telemetry, canvas APIs, field testing, packaging, and wrapup; require a separate review of every release PR.
- **Bun:** 1.4.2 → 1.4.3 for the package-manager pin and container images.

## Fixed

- **Text precision:** retain upstream station coordinates and coverage values; label coverage as a raw 0–1 fraction ([#30](https://github.com/cyanheads/noaa-climate-mcp-server/issues/30)).
- **CDO pagination:** echo the requested zero-based offset in returned metadata and text across all seven collection tools ([#37](https://github.com/cyanheads/noaa-climate-mcp-server/issues/37)).
- **Upstream failures:** name the NOAA operation and network, timeout, or HTTP cause without an origin URL in caller-visible messages ([#29](https://github.com/cyanheads/noaa-climate-mcp-server/issues/29)).

- `zod` ^4.6.5 → ^4.6.7.
