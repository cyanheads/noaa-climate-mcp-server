# 0.9.0 — 2026-11-11

## Added

- **`noaa_climate_get_normals`** reads one station's 1991–2020 U.S. Climate Normals (monthly, daily, hourly, annual/seasonal) from NCEI's keyless Access Data Service, in native units with `completeness` and `years` per record. Units are labeled only where verified (°F, in, base-65 °F-days, hPa); the MM/DD frost dates come back as `valueText`; a GHCN station ID is uppercased only when written all in lowercase ([#53](https://github.com/cyanheads/noaa-climate-mcp-server/issues/53)).
- **`noaa_climate_search_storm_events`** returns `stateFips`, `czFips`, `cdoLocationId` (county rows outside Alaska and the territories), `wfo`, `beginLocation`, `endLatitude`, and `endLongitude`, and takes a `countyFips` filter ([#54](https://github.com/cyanheads/noaa-climate-mcp-server/issues/54)).
- **`noaa_climate_fetch_data` notices on `NORMAL_*` pages** flag datatypes CDO mis-converts under `units=metric` (omit `units` and convert the raw values) and NCEI special values (-9999, -7777, -6666, -4444).

## Changed

- **CDO `NORMAL_*` wording** in `noaa_climate_fetch_data`, `noaa_climate_list_datasets`, `noaa://datasets`, the server instructions, and the guide skill now calls these datasets the superseded 1981–2010 normals and routes 1991–2020 questions to `noaa_climate_get_normals` ([#53](https://github.com/cyanheads/noaa-climate-mcp-server/issues/53)).
- **`noaa_climate_search_storm_events`** default `limit` 50 → 10; the `countyOrZoneType` description covers C, Z, and M.

## Fixed

- **Upstream HTML error pages** reach the caller as `HTTP <status> (<title>)` instead of markup, now that mcp-ts-core 0.13.22 keeps captured error bodies off client envelopes.
